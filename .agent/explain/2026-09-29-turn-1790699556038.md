## 3. The alternative

The previous approach scanned every project’s `.agent` files, excluding only the map directory. This patch skips neutrality checks for the harness itself and excludes both map and explain output for other projects. That fits the distinction between the harness’s own notes and memory intended to stay neutral in projects that use the scaffold. A configurable allowlist or metadata-based output classification could be more flexible, but would add machinery for the two known generated directories.
