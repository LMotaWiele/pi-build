## Unfamiliar surface

No unfamiliar language features, standard-library calls, or library APIs were introduced in the code changes. The test now uses a source-reading seam rather than loading the extension, avoiding its unavailable `typebox` dependency in the standalone Node test environment.

## The alternative

The test previously imported and ran the memory-gate extension, checking registered tools and injected prompt text at runtime. The source-level check won because Node’s standalone test environment cannot resolve pi’s bundled `typebox`; it still guards the declared tool names and absence of `explain_write` without adding test setup for pi’s runtime dependencies.
