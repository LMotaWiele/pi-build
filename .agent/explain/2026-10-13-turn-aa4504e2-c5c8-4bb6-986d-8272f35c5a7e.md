## Unfamiliar surface

- `node:module`’s `registerHooks` and `createRequire` — adds a Node module-resolution hook and resolves dependencies from the installed pi package; used by the temporary compatibility loader to find dependencies the test environment cannot resolve.
- Node’s test-runner mock timers (`t.mock.timers.enable` and `.tick`) — controls timer progression in tests; used to exercise quota-gate retry behavior without waiting in real time.

## To modify this yourself

Read the relevant extension and test files together: `extensions/bounds.ts` with `tests/bounds-split.test.ts`, `extensions/memory-gate.ts` with `tests/memory-owner.test.ts`, `extensions/read-guard.ts` with `tests/read-guard-content.test.ts`, and `extensions/quota-gate.ts` with `tests/quota-gate-refresh.test.ts`. The compatibility loader is temporary test setup; change it only if dependency resolution needs to change.
